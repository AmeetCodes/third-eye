# Third Eye - Real-Time Tender Dashboard

A premium Next.js dashboard for monitoring government tenders and project transparency in Nepal.

## ✨ Features
- **Real-Time Feed**: Fetches live data from the Bolpatra API.
- **Civic Intelligence**: Automated synchronization and storage in MongoDB Atlas.
- **Smart Analysis**: Identifies "Red Flags" like short deadlines or single-source bids.
- **Rich Media**: Renders official tender notice images with full-size viewing support.
- **Paginated Insights**: High-performance, server-side paginated data fetching.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- Backend running on port 5000 (see `/backend`)

### Installation
1. `npm install`
2. `npm run dev`

### Access
Open [http://localhost:3000/tenders](http://localhost:3000/tenders) to see the live feed.
